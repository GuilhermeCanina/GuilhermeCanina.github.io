# Portfólio — Guilherme Canina

Site estático de portfólio publicado pelo GitHub Pages em `guinino.dev.br`.

## Arquivos

- `index.html`: conteúdo semântico, metadados SEO e dados estruturados da página.
- `style.css`: estilos, responsividade, identidade visual, estudos de caso, botões e tema alternativo.
- `script.js`: navegação suave, ano dinâmico e easter eggs do site.
- `docs/curriculo-guilherme-canina.pdf`: currículo ATS-friendly em PDF para download.
- `favicon.svg`: ícone do site alinhado à paleta escura/roxa.
- `robots.txt` e `sitemap.xml`: instruções e mapa básico para mecanismos de busca.
- `img/`: GIF original da Lain (easter egg), versão WebP animada mais leve para o fundo, imagem estática para usuários que preferem movimento reduzido e badges de credenciais.
- `CNAME`: domínio personalizado do GitHub Pages.

## Seções

- Apresentação com links para projetos, GitHub e currículo PDF.
- Sobre mim, experiência profissional e formação acadêmica.
- Estudo de caso resumido do aplicativo de força de vendas, sem detalhes proprietários.
- Projetos acadêmicos e pessoais.
- Certificações e credenciais.
- Habilidades em texto legível por máquinas e cartões visuais.
- Contato e Instagram como canal secundário.

## Publicação

O projeto não exige build nem instalação de dependências. Para publicar, envie os arquivos para a branch configurada no GitHub Pages, mantendo o arquivo `CNAME` e a pasta `img/`.

## Interações e acessibilidade

- O nome no cabeçalho pode ser acionado por clique ou teclado para revelar um easter egg.
- `Ctrl + M` alterna entre o tema escuro e o claro.
- O botão no rodapé revela/oculta o GIF original da Lain; o arquivo só é carregado quando o easter egg é acionado.
- O fundo usa uma versão WebP animada com a mesma arte para reduzir o tamanho transferido; a preferência por movimento reduzido usa uma imagem estática.
- A navegação inclui um link para pular diretamente ao conteúdo principal.
- Elementos interativos têm estados de foco visíveis; imagens decorativas são ignoradas por leitores de tela.
- Metadados de compartilhamento, URL canônica, dados estruturados Person, `robots.txt` e `sitemap.xml` foram adicionados.
- O currículo é servido como PDF independente e com texto selecionável. O portfólio não publica automaticamente alterações na hospedagem.
