# Portfólio — Guilherme Canina

Site estático de portfólio publicado pelo GitHub Pages em `guinino.dev.br`.

## Arquivos

- `index.html`: conteúdo e estrutura da página.
- `style.css`: estilos, responsividade e temas.
- `script.js`: interações e easter eggs do site.
- `img/`: GIFs utilizados no site e a medalha oficial da microcredencial AWS, fornecida no arquivo `img/aws-data-visualization-demonstrated.png`.
- `CNAME`: domínio personalizado do GitHub Pages.

## Publicação

O projeto não exige build nem instalação de dependências. Para publicar, envie os arquivos para a branch configurada no GitHub Pages, mantendo o arquivo `CNAME` e a pasta `img/`.

## Detalhes

- O nome no cabeçalho pode ser clicado para revelar um easter egg.
- `Ctrl + M` alterna entre o tema escuro e o claro.
- Clicar no rodapé revela o GIF da Lain.
- A seção “Certificações” destaca a microcredencial AWS Data Visualization Demonstrated.
