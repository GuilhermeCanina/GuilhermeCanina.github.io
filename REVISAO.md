# Revisão do portfólio — 14/10/2026

Esta versão foi preparada como uma cópia independente do site original. Não foi publicada automaticamente.

## Alterações

- Preservados o tema escuro/roxo, a arte da Lain, os easter eggs e o atalho `Ctrl + M`.
- Refinado o hero com stack em texto e ações para projetos, GitHub e currículo.
- Adicionada a seção de formação acadêmica.
- Melhorada a leitura da experiência profissional com tópicos e uma entrega factual.
- Criado um estudo de caso de alto nível do aplicativo de força de vendas, sem nomes de clientes, dados internos ou detalhes proprietários.
- Reorganizados os textos das competências para que as tecnologias também estejam legíveis como texto, não somente em ícones.
- Adicionada a aplicação do Manga Reader a partir do endereço público associado ao repositório.
- Incluído o currículo ATS-friendly em `docs/curriculo-guilherme-canina.pdf`, com texto selecionável e layout simples de uma coluna.
- Adicionados canonical URL, metadados de compartilhamento, JSON-LD `Person`, favicon, `robots.txt` e `sitemap.xml`.
- Ajustes para responsividade, foco de teclado, movimento reduzido e contraste dos controles.

## Validações executadas

- JavaScript verificado com `node --check`.
- IDs HTML sem duplicatas e âncoras internas conferidas.
- Caminhos locais de links, scripts, folhas de estilo, imagens e PDF conferidos.
- CSS analisado sintaticamente.
- JSON-LD parseado como JSON e sitemap validado como XML.
- PDF confirmado como texto extraível e com uma página.

As URLs externas podem depender de disponibilidade e alterações nos respectivos serviços; conferir novamente ao publicar. Para a credencial Microsoft, o site aponta para a página oficial da Applied Skills, não para uma página individual de verificação.
